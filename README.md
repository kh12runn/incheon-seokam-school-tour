# 인천석암초등학교 · 학교 전체 3D 모델

공개 웹: https://school-tour-production.up.railway.app/

Railway `school-tour` 서비스가 이 저장소의 `main`을 배포합니다. PC 키보드·마우스로 탐험하며 시작 항공뷰 자동회전과 4층 실사 사진 9장이 포함됩니다.

기존 샘플 360 웹 투어를 현재 **Blender ㄱ자 학교 모델 + 촬영 준비 프로젝트**로 교체했습니다. 설계도면은 형태, 2026 교실배치도는 실명 기준입니다. 치수와 촬영 위치는 근사값이며 현장 확인이 필요합니다.

## 웹에서 걸어 다니기 — 현재 실행 방법

`학교_웹_열기.cmd`를 더블클릭하면 로컬 웹 서버와 브라우저가 열립니다. Node.js가 필요하며 Blender를 켜둘 필요는 없습니다. **학교 탐험 시작하기**를 누르세요.

- WASD: 이동 / 마우스: 시점 / Shift: 빠르게 / ESC: 정지와 메뉴
- 네 계단 모두 보행으로 1~4층 왕복 가능, 벽·창문 충돌 적용
- 전체 보기: 드래그 회전·휠 확대 / 층별 단면 / 교실 바로 가기
- 마우스 잠금이 지원되지 않으면 드래그 시점 방식으로 자동 전환
- 지도에서 보라색은 계단. 교실 41곳과 층별 표식 4개를 탐험하는 진행 표시

원본 Blender에서 1,802개 상자 구조와 218개 글자 정보를 추출했습니다. 원본의 장식용 계단과 막힌 계단 바닥은 웹에서만 보행 가능한 왕복 계단·중간참·개구부로 교체했습니다. `.blend` 원본은 변경하지 않았습니다. 4층 복도·계단 INSP 9장은 직접 변환하고 촬영자를 제거하여 **‘4층 실사 360도’**로 연결했습니다. 실사 보기에서는 드래그로 둘러보고 W/S로 촬영 지점 사이를 이동합니다. 3DGS 또는 기존 메시의 실사 UV 텍스처화는 아닙니다.

## Blender에서 편집하기

Windows에서 `학교_3D_열기.cmd`를 더블클릭하세요. Blender 5.2 설치 환경에서 검증했습니다. 다른 설치 경로에서는 `BLENDER_EXE` 환경 변수로 실행 파일 경로를 지정할 수 있습니다. 한글 표지는 Windows 맑은 고딕을 사용합니다.

- N → 학교 → 전체 / 1~4층 입체 / 배치도
- 선택한 층 걷기 시작 → WASD 이동, 마우스 시선, ESC 종료
- 걷는 중 1~4 → 층 이동. 계단을 직접 걸어 오르내리기는 아직 미지원입니다.

`모델/school_master.blend`만 직접 열면 사용자 정의 버튼이 등록되지 않을 수 있으므로 실행용 CMD를 사용하세요. GitHub ZIP 다운로드에는 프로젝트 전체가 들어 있습니다.

현재 `index.html`은 실시간 웹 3D 화면입니다. 2026-09-10 사용자 요청으로 GitHub 업로드와 Railway 배포를 준비했습니다. Three.js 파일을 프로젝트에 포함하여 실행 중 외부 CDN에 의존하지 않습니다. Railway는 `Dockerfile`과 `railway.toml`을 사용하며 `/healthz`로 상태를 확인합니다. `PORT`가 있으면 외부 수신, 없으면 기존 로컬 전용 서버입니다.

## 사진을 넣는 곳

로컬 `석암초등학교` → `촬영사진_넣는곳` → 층 → 교실 / 특별실_지원실 / 복도 / 계단 순서로 들어가세요. 원본 사진·영상을 여러 장 넣고 폴더명을 알려주시면 다음 단계에서 확인합니다. 자동 학습이나 자동 업로드는 하지 않습니다. 일반 폴더 이름은 전부 한글이며, Git 동작에 필요한 숨김 관리 폴더만 예외입니다.

- 교실 41개, 특별실·지원실 39개(외부 지킴이실 포함)
- 복도 15구간 + 실 앞 복도 세부 지점 80개
- 계단 위치 16개(층당 4개), 계단참 16개, 층간 올라가는 구간 12개
- 배치도에서 확인한 교실 앞 야외계단 1개를 추가하여, 현관·외부·기타·미분류까지 촬영 폴더 총 243개

계단 예: `4층/계단/6-3 교실 앞 6학년 연수실 옆 계단`. 사용자가 제공한 2026 교실배치도 PDF를 직접 확인하여 이름을 수정했습니다. 본관 중앙 계단은 4층 6-3 앞, 3층 5-3 앞, 2층 교무실 앞, 1층 본관 출입구 뒤입니다. 이전 근사 모델 기준의 6-2·5-2 별칭은 사용하지 않습니다. 별관 1층 두 지점은 PDF에 출입구로만 표시되어 있어 계단의 실제 위치와 연결은 확인이 필요합니다.

올라가는 구간 사진은 아래층 계단의 `02_…올라가는구간` 폴더에 넣습니다. 4층 위와 1층 아래는 도면만으로 용도·동선이 확정되지 않아 만들지 않았습니다. 화장실은 기본 촬영 제외이며 허가와 무인 상태 확인이 먼저입니다.

## 공개 범위와 백업

사용자 승인 범위에 따라 모델·스크립트·공간 목록·미리보기·폴더 안내문과 촬영자 제거를 마친 웹용 사진 9장을 포함합니다. `촬영사진_넣는곳`의 사진/영상, `사진보관`의 원본·변환본, `참고자료`, 모델 백업과 비밀키는 Git에서 제외합니다. **GitHub 웹 화면에 사진을 직접 올리면 이 제외 규칙이 적용되지 않습니다.** 학생 얼굴·명단 등 개인정보는 촬영 단계부터 피하세요.

기존 투어의 커밋 이력은 유지하며 강제 푸시하지 않습니다. 교체 전 미커밋 작업과 사진, 한글화 전 폴더도 로컬 백업에 보존했습니다. 이전 원본 프로젝트는 그대로 두었고 앞으로의 로컬 작업 기준은 `석암초등학교`입니다. 기본 배포 대상은 Railway이며 GitHub Pages 워크플로는 수동 실행만 허용합니다.

## 개발·검증

- `node 관리도구/웹서버.mjs`: 로컬 서버 (기본 8080, 사용 중이면 다음 포트)
- `node 웹학교/검사/이동검사.mjs`: 4개 층 복도·41개 교실 문·4개 계단 왕복·운동장·벽 충돌 검사
- Blender의 `모델/실행도구/export_web.py`: `.blend`를 수정하지 않고 웹 구조 재추출
- `웹학교/게임.mjs`: 화면·입력 / `웹학교/이동물리.mjs`: 보행·충돌
- `안내문서/웹학교 사용법.md`: 조작법과 제한 사항

- `공간자료/spaces.json`: 공간 ID·위치·기존 처리 경로·새 `intakeFolder`의 기준
- `공간자료/capture-manifest.json`: 촬영 폴더와 교실/계단/복도 ID 연결표
- `node 관리도구/generate-capture-folders.mjs`: 안내문과 목록 재생성(사진 삭제 없음)
- `모델/실행도구/build_campus.py`: 전체 모델 재생성. 먼저 백업하며 현재 Blender 장면을 변경합니다.
- `모델/실행도구/prepare_release.py`: 이 프로젝트의 저장된 모델을 점검하고 배포 경로를 정리합니다.
- `build_prototype.py`, `walk_preview.py`, `scaffold_project.py`, `reconcile_intake.py`는 이전 제작 이력입니다. 현재 데이터에 임의로 재실행하지 마세요.
