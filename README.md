# 인천석암초등학교 · 학교 전체 3D 모델

기존 샘플 360 웹 투어를 현재 **Blender ㄱ자 학교 모델 + 촬영 준비 프로젝트**로 교체했습니다. 설계도면은 형태, 2026 교실배치도는 실명 기준입니다. 치수와 촬영 위치는 근사값이며 현장 확인이 필요합니다.

## 3D로 열기

Windows에서 `학교_3D_열기.cmd`를 더블클릭하세요. Blender 5.2 설치 환경에서 검증했습니다. 다른 설치 경로에서는 `BLENDER_EXE` 환경 변수로 실행 파일 경로를 지정할 수 있습니다. 한글 표지는 Windows 맑은 고딕을 사용합니다.

- N → 학교 → 전체 / 1~4층 입체 / 배치도
- 선택한 층 걷기 시작 → WASD 이동, 마우스 시선, ESC 종료
- 걷는 중 1~4 → 층 이동. 계단을 직접 걸어 오르내리기는 아직 미지원입니다.

`blender/school_master.blend`만 직접 열면 사용자 정의 버튼이 등록되지 않을 수 있으므로 실행용 CMD를 사용하세요. GitHub ZIP 다운로드에는 프로젝트 전체가 들어 있습니다.

GitHub Pages의 `index.html`은 최신 모델 이미지와 다운로드 안내입니다. **브라우저용 실시간 3D 뷰어가 아닙니다.** 실제 3D 탐색은 Blender에서 합니다. 360 사진 투영과 가우시안 스플래팅 학습은 아직 수행하지 않았습니다.

## 사진을 넣는 곳

`촬영사진_넣는곳` → 층 → 교실 / 특별실_지원실 / 복도 / 계단 순서로 들어가세요. 원본 사진·영상을 여러 장 넣고 폴더명을 알려주시면 다음 단계에서 확인합니다. 자동 학습이나 자동 업로드는 하지 않습니다.

- 교실 41개, 특별실·지원실 39개(외부 지킴이실 포함)
- 복도 15구간 + 실 앞 복도 세부 지점 80개
- 계단 위치 16개(층당 4개), 계단참 16개, 층간 올라가는 구간 12개
- 현관·외부·촬영 전 허가가 필요한 기타 공간과 미분류 폴더까지 안내문이 있는 촬영 폴더 총 242개

계단 예: `4층/계단/본관_중앙_B__6-2 교실_앞_계단_위치확인필요`. 사용자 예시인 6-1 앞을 실제 계단으로 단정하지 않고 현재 모델의 인접 교실로 이름을 붙였습니다. 실제 위치를 확인해 주세요. 계단 A/B/D/E는 층이 달라도 같은 수직 계단입니다.

올라가는 구간 사진은 아래층 계단의 `02_…올라가는구간` 폴더에 넣습니다. 4층 위와 1층 아래는 도면만으로 용도·동선이 확정되지 않아 만들지 않았습니다. 화장실은 기본 촬영 제외이며 허가와 무인 상태 확인이 먼저입니다.

## 공개 범위와 백업

공개 저장소에는 모델·스크립트·공간 목록·미리보기·폴더 안내문만 올립니다. `촬영사진_넣는곳`의 사진/영상, `photos`, 원본 참고자료, Blender 백업은 Git에서 제외합니다. **GitHub 웹 화면에 사진을 직접 올리면 이 제외 규칙이 적용되지 않습니다.** 학생 얼굴·명단 등 개인정보는 촬영 단계부터 피하세요.

기존 투어의 커밋 이력은 유지하며 강제 푸시하지 않습니다. 교체 전 미커밋 작업과 사진도 작업 폴더 바깥의 로컬 백업에 보존했습니다. 이전 `seokam-virtual-school`은 그대로 두었고 앞으로의 작업 기준은 이 `school-tour`입니다.

## 개발·검증

- `data/spaces.json`: 공간 ID·위치·기존 처리 경로·새 `intakeFolder`의 기준
- `data/capture-manifest.json`: 촬영 폴더와 교실/계단/복도 ID 연결표
- `node scripts/generate-capture-folders.mjs`: 안내문과 목록 재생성(사진 삭제 없음)
- `blender/scripts/build_campus.py`: 전체 모델 재생성. 먼저 백업하며 현재 Blender 장면을 변경합니다.
- `blender/scripts/prepare_release.py`: 이 프로젝트의 저장된 모델을 점검하고 배포 경로를 정리합니다.
- `build_prototype.py`, `walk_preview.py`, `scaffold_project.py`, `reconcile_intake.py`는 이전 제작 이력입니다. 현재 데이터에 임의로 재실행하지 마세요.
