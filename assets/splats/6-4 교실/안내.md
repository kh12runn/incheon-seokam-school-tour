# 첫 실사 심화 시범 공간: 6-4 교실

사용자 지정: 2026-09-10. 본관 4층, 기존 공간 ID `4F_6-4`.
준비 장면 ID `4F_6-4_SPLAT_01`. 대상만 지정되었으며 실제 Splat·충돌 GLB·Viewer는 아직 없습니다. 기존 교실 모델과 다른 교실, UI는 변경하지 않습니다.

## 현재 자료

기존 촬영 폴더 `촬영사진_넣는곳/4층/교실/6-4 교실/`에 `6-4_원본_1.insp`, `6-4_원본_2.insp`가 있습니다. 파일을 이동하거나 수정하지 않습니다. 기존 인물 제거 파노라마는 참고 자료이며, 생성 보완 부분을 실제 관측이나 재구성 원본으로 간주하지 않습니다.

## 현재 작업 방식 — 기존 두 사진만 사용

사용자가 사진은 두 장뿐이라고 명시하고, Splat 대신 기존 모델의 사진 기반 마감을 승인했습니다. **추가 촬영을 요청하지 않습니다.** 현재 사진의 기존 인물 제거 편집본에서 확인 가능한 표면만 웹 UV로 적용하며 다른 교실은 별도 사진을 받은 뒤 각각 처리합니다. Splat 등록은 삭제하지 않고 비활성 보류 상태로 남깁니다.

Gaussian Splat은 여러 시점의 겹치는 관측에서 재구성합니다. 현재 앞뒤 두 촬영 지점만으로 교실 전체 자유 이동 품질을 보장하지 않습니다. 이동하며 찍은 자료가 필요하고, 영상 업로드 자체가 Splat 완성을 뜻하지 않습니다. 영상 변환·프레임 추출·카메라 정렬·학습 도구와 품질은 원본 확인 후 결정합니다. [공식 제작 흐름](https://developer.playcanvas.com/user-manual/gaussian-splatting/creating/)

정면 벽 사진을 이용한 Blender Texture Bake는 별도 경로입니다. 현재 작업은 Blender 베이크나 Gaussian 재구성이 아니며 새로운 생성형 이미지도 만들지 않습니다.

## 검수 후 연결

원본 보존 → 사본 재구성/편집 → SOG → 단순 GLB 충돌 및 좌표 정렬 → 고정 버전 Viewer 검증 → 개인정보/성능/공개 승인 → 실사 버튼 연결.

준비 목록은 `enabled: false`, 파일 URL은 `null`입니다. 등록된 기본 복귀점은 현재 6-4 교실의 안전한 시작점이며, 추후 실제 왕복 구현에서는 출발 위치를 우선 복원합니다. 아직 왕복 동작은 구현하지 않았습니다.
