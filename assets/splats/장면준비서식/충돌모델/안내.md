# 충돌모델

지정 구역만의 단순화 GLB를 별도로 준비할 자리입니다. 학교 시각 모델 전체를 그대로 넣지 않습니다. 현재 GLB는 생성하지 않았습니다.

바닥·벽·필요한 계단·출입 제한 구조를 포함하고, 통과 가능한 문은 개구부를 유지합니다. 책상·의자·창틀·게시판의 세부 형상은 제외하며 큰 가구를 막아야 하면 단순 충돌 상자를 사용합니다.

현재 웹용 구조 보정과 원본 Blender 구조는 다릅니다. 최신 실제 동선에 맞춘 뒤 Splat과 같은 Y-up·미터 좌표로 정렬하고 검증합니다. GLB 방식이 우선 후보이며 자동 voxel은 별도 비교 후보입니다.
