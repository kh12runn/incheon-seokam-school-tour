# 실사 심화 공간 준비 폴더

첫 시범 공간은 사용자가 지정한 **6-4 교실**입니다. 준비 항목 1개를 등록했지만 실제 Splat 파일은 없으며 비활성입니다. Viewer 설치, 웹 연결, 공개 배포는 하지 않았습니다.

요청에서 지정한 `assets/splats/` 경로를 사용하되, 내부 촬영·관리 폴더는 혼동을 줄이도록 한글로 사용합니다. 기존 `촬영사진_넣는곳`과 `사진보관`은 이동·변경하지 않습니다.

```
assets/splats/
├── 장면목록.json         6-4 교실 준비 항목 1개, 전체 비활성
├── 장면등록서식.json     복사해서 쓸 서식, 실제 장면 아님
├── 6-4 교실/            원본보존 / 웹용경량본 / 충돌모델 / 뷰어
└── 장면준비서식/         공간을 임의 선정하지 않은 폴더 서식
    ├── 원본보존/         source: PLY / SPZ
    ├── 웹용경량본/       optimized: 검수한 SOG
    ├── 충돌모델/         collision: 단순화 GLB
    └── 뷰어/             viewer: 버전 고정한 Viewer App
```

사용자가 지정한 `6-4 교실`만 별도 한글 공간명 폴더로 준비했습니다. [6-4 교실 안내](6-4%20교실/안내.md)를 확인하세요. 도서관·다목적실·4층 복도 및 다른 일반 교실은 등록하지 않습니다.

원본은 새 이름으로 보존하고 SHA-256·취득일·촬영 위치·권한을 로컬 기록합니다. PLY/SPZ를 자동 삭제하거나 덮어쓰지 않습니다. 이 저장소 안의 보관만으로 재해 백업이 되지는 않으므로 학교 소유의 별도 저장장치에도 사본을 보관하세요.

이 폴더는 현재 Git에 안내·등록 서식만 포함하며 스캔·변환본·뷰어 출력물은 기본 제외됩니다. Railway 업로드에서도 전체 제외합니다. `.gitignore`는 이미 추적된 파일이나 GitHub 직접 업로드를 보호하지 않습니다. 학생 얼굴·이름·작품 이름·게시판·문서·화면은 사람이 검수하며, 생성형 삭제만으로 검수 완료로 간주하지 않습니다. 원본을 외부 서비스에 자동 업로드하지 않습니다.

장면을 실제 활성화하려면 공간 지정, 개인정보 검수, SOG 파일 확인, 설치 버전/API 확인, 좌표 정렬, 충돌·복귀·성능 검증, 공개 승인 및 배포 허용 목록 갱신이 모두 필요합니다. `enabled` 하나를 바꿔도 현재 게임은 연결되지 않습니다.
