관리자 로그인

업로드 후 소유자의 승인을 기다립니다. 사진만으로 학교 모델이 자동 변경되지는 않습니다.

관리자

공간 선택

원본은 비공개 GitHub 저장소에 보관합니다. 학생·교직원 얼굴, 이름, 연락처가 포함된 사진은 공개 승인 전에 제거·가림 처리하세요. 이 기능은 자동 인물 제거 또는 자동 3D 생성 기능이 아닙니다.

사진을 이곳에 끌어다 놓으세요

JPG · JPEG · PNG · WEBP / INSP는 JPG로 변환 후 업로드

저장된 사진

2:1 비율은 ‘360 후보’로 표시합니다. 실제 파노라마 여부와 촬영 방향은 구현할 때 확인합니다.

소유자 전용

승인은 사진 자료 등록입니다. 실제 모델 반영은 별도로 요청해주세요. ‘구현 완료’도 진행 현황 표시만 변경합니다.

소유자 인증

업로드 로그인과 다른 비밀번호를 입력하세요. 승인 권한은 30분 동안 유지됩니다.
