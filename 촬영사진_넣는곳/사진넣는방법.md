# 사진 넣는 방법

촬영한 360도 사진을 해당 건물, 층, 장소 폴더에 넣어주세요.

## 가장 쉬운 파일 이름

같은 장소에서 촬영한 순서대로 숫자만 붙이면 됩니다.

```text
01.jpg
02.jpg
03.jpg
```

복도는 A, B, C 같은 문자 대신 가까운 교실이나 특별실 이름으로 나누었습니다.
촬영한 위치와 가장 가까운 이름의 복도 폴더에 넣어주세요.

```text
본관/3층/복도/5-3앞_복도/01.jpg
본관/3층/복도/5-2앞_복도/01.jpg
본관/3층/복도/5-1앞_복도/01.jpg
```

정확히 어느 교실 앞인지 애매하면 가장 가까운 교실 폴더를 선택하면 됩니다. 한 복도 위치에서 여러 장을 촬영했다면 같은 폴더 안에서 `01.jpg`, `02.jpg` 순서로 넣어주세요.

계단과 화장실도 문자나 숫자 대신 주변 교실 이름으로 구분했습니다.

```text
본관/3층/상담실_5-7사이_계단/01.jpg
본관/3층/5-3_5-2사이_계단/01.jpg
본관/3층/5-7쪽_화장실/01.jpg
본관/3층/5-2쪽_화장실/01.jpg
```

교실 내부 사진은 해당 교실 폴더에 넣습니다.

```text
본관/3층/5-2/01.jpg
```

## 영상도 넣을 경우

영상은 해당 장소 폴더에 사진과 함께 넣고 `route_01.insv`처럼 이름을 붙여주세요.

```text
본관/3층/복도/5-2앞_복도/route_01.insv
```

## 주의사항

- Insta360 원본 `INSP`, `DNG`, `INSV` 파일은 삭제하지 마세요.
- 내보낸 2:1 비율의 360 JPG가 있다면 원본과 함께 넣어도 됩니다.
- 복도 사진 번호는 실제로 걸어간 순서와 같아야 합니다.
- 같은 장소의 사진이 여러 장이면 번호를 빠뜨리지 말아주세요.
- 학생 얼굴, 이름표, 게시물의 개인정보가 보이지 않는지 확인해주세요.
- 폴더가 부족하거나 장소명이 다르면 새 폴더를 직접 만들지 않아도 됩니다. 저에게 장소명만 알려주시면 추가하겠습니다.

사진을 모두 넣은 뒤 채팅으로 다음처럼 알려주세요.

> 본관 3층 5-2 앞 복도에 사진을 넣었어. 오른쪽 문이 5-2 교실이야.

그러면 장면 등록, 앞뒤 이동, 교실 연결, 현재 위치와 미니맵을 업데이트합니다.
