# 교장선생님 3D 캐릭터

- `교장선생님-실물.glb`: 로컬 검토에서 확정한 `principal-realistic-v4.glb`. 부드러운 얼굴 v3에 얼굴 앞면 밝기 보정 v4를 적용한 모델입니다. 표시 키 1.84m로 배치합니다.
- `교장선생님-귀여운.glb`: 로컬 검토에서 확정한 `principal-cute.glb`.
- 제작: 사용자 제공 교장선생님 사진을 참고한 전신 시안으로 Meshy 7.1에서 생성·리메시하고, 실물형 얼굴을 추가 수정했습니다. 3D 스캔이 아니며, 리깅이나 걷기 애니메이션은 포함하지 않습니다.
- 배포 파일은 검토한 GLB에서 형상·재질·몸 비율을 보존했습니다.
- 사용자 요청에 따라 두 모델을 학교 웹앱 교장실에 통합합니다. 별도 오픈 라이선스를 부여하는 자료는 아닙니다.
