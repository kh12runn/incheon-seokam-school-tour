# 실제 360도 사진을 게임풍으로 다듬는 방법

## 현재 사이트의 기본 방식

현재 버전은 모바일 성능과 관리 편의성을 위해 다음 방식을 사용합니다.

1. 실제 360도 사진 원본을 로컬 촬영 폴더에 보존합니다.
2. 촬영자, 손, 휴대전화와 개인정보가 보이는 부분을 제거합니다.
3. 문, 창문, 복도 방향과 공간 배치는 바꾸지 않습니다.
4. 색감과 재질 표현만 가볍게 게임풍으로 다듬습니다.
5. 처리된 2:1 파노라마를 Pannellum에서 표시합니다.
6. 가까운 촬영 지점은 이동 아이콘과 WASD로 연결합니다.

이 방식은 사진 속 실제 학교 모습을 쉽게 알아볼 수 있고 스마트폰에서도 안정적으로 동작합니다. 별도의 3D 자유이동 모델은 만들지 않습니다.

## 사진을 전달할 때 필요한 정보

```text
파일 이름: MAIN_3F_HALL_04.jpg
위치: 본관 3층 5-3 앞
정면: MAIN_3F_HALL_05
뒤쪽: MAIN_3F_HALL_03
오른쪽 문: 5-3 교실
원본 보존: 예
```

원본 파일은 건드리지 않고 `-game`이 붙은 처리 파일을 별도로 만들어 연결합니다.
