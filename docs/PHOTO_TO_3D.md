# 실제 사진을 3D 느낌으로 사용하는 방법

## 현재 사이트의 기본 방식

현재 버전은 모바일 성능과 관리 편의성을 위해 다음 방식을 사용합니다.

1. 실제 360도 사진 원본을 별도로 보존합니다.
2. 공간 구조가 바뀌지 않도록 2:1 파노라마를 가벼운 3D 게임 렌더링 스타일로 변환합니다.
3. 변환된 파노라마를 Pannellum에서 표시합니다.
4. 실제 공간 이동은 서로 가까운 촬영 지점을 화살표로 연결합니다.

이 방식은 용량이 작고 스마트폰에서도 안정적이지만, 한 scene 안에서 카메라가 앞뒤로 자유롭게 걷는 진짜 6DoF 모델은 아닙니다.

## 진짜 Gaussian Splat 모델을 만들고 싶을 때

Gaussian Splat은 한 장의 360도 사진보다 **같은 공간을 여러 위치에서 찍은 겹치는 영상이나 사진 묶음**이 필요합니다.

- 한 공간을 천천히 걸으며 촬영한 동영상
- 또는 서로 60~80% 이상 겹치는 여러 위치의 사진
- 움직이는 학생이나 물체가 적은 시간대
- 자동 노출 변화가 적고 밝기가 일정한 촬영
- 문, 복도 모서리, 계단처럼 위치를 식별할 특징이 충분한 화면

이 자료가 준비되면 별도 학습 과정으로 `.ply` 또는 `.splat` 모델을 만들고 WebGL 뷰어를 추가할 수 있습니다. 모델 용량과 스마트폰 성능을 확인한 뒤 중요한 공간부터 선택적으로 적용하는 것이 좋습니다.

```text
위치: 본관 3층 5-3 앞
정면: MAIN_3F_HALL_05
뒤쪽: MAIN_3F_HALL_03
오른쪽 문: 5-3 교실
원본 보존: 예
```

원본 파일은 건드리지 않고 `-3d`가 붙은 변환 파일을 별도로 만들어 연결합니다.
