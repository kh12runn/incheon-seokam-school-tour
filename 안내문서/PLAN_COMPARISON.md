# 설계도면과 2026 교실배치도 비교

## 적용 기준

사용자가 대화에 첨부한 건축물현황도 5장: 1층, 2층, 3층, 4층, 지하/PIT. 파일 경로가 제공되지 않아 대화의 이미지를 직접 판독했다. 도면의 가로 본관과 동쪽에서 남쪽으로 이어지는 별관은 전체적으로 ㄱ자다. 본관 중앙의 동서 복도가 별관 동쪽의 남북 복도와 연결된다.

건물 외형·복도·계단의 대략적인 위치는 설계도면으로, 현재 교실과 특별실 명칭은 2026학년도 교실배치도로 정했다. 도면의 예전 `교실-1`, `교실-2` 및 옛 용도는 현행 학급명을 대신하지 않는다. 크기는 사용자 요청에 따라 비슷한 비율로 단순화했다. 도면에 축척·치수선은 있으나 현재 모델 수치는 정밀 전사값이 아니다.

## 비교 결과와 반영

| 항목 | 자료 비교 | 모델 반영 |
|---|---|---|
| 건물 형태 | 1~4층 도면에 가로 본관 + 세로 별관 | 4층 ㄱ자 두 동, 운동장을 안쪽에 배치 |
| 본관 복도 | 가로로 이어지는 중심 동선 | 동서 방향 복도와 계단 A/B |
| 별관 복도 | 교실열 동쪽의 세로 동선 | 남북 복도, 계단 D/E |
| 학급명 | 설계도면은 옛 교실 번호, 배치도는 2026 학급명 | `6-1 교실`, `6-2 교실` 등 현행 이름 |
| 본관 1층 | 배치도에 3학년 교실·행정·보건·급식 공간 | 3-4~3-1, 현관, 행정실, 보건실, 발간실, 급식실 등 |
| 본관 2층 | 시청각실·돌봄·교무/과학 계열 | 교장실·교무실·방송실·과학실 등 현행 표기 |
| 본관 3층 | 5학년 교실 + 4학년 일부·도서관 | 5-7~5-1, 4-5, 4-6, 책터 도서관 |
| 본관 4층 | 6학년 교실 + 4학년 일부 | 6-7~6-1, 4-1~4-3 |
| 별관 학급 분산 | 배치도는 층을 열 방향으로 나열 | 학년으로 층을 추측하지 않고 각 열에 맞춰 배치 |
| 지하/PIT | 서쪽 일부에 제한된 공간, 현재 용도 불명 | UNKNOWN 단순 체적, 기본 화면에서 숨김 |

## 정확도가 제한된 부분

1~4층 건물 폭과 교실 크기는 근사값이다. 창호·문 수와 위치, 계단 디딤판과 층간 개구부는 단순화했다. 지하 공간의 용도와 세부 실명은 확인하지 못했다. 2026 배치도의 부속 출입구·지킴이실 반복 표시는 외부 영역으로 요약했다. 이 모델은 학교와 비슷한 모습을 확인하기 위한 것이다.

각 실명은 Blender 바닥 라벨과 출입문 표지, `공간자료/spaces.json`, `안내문서/ROOM_NAMES.md`에서 확인할 수 있다. 내부를 보려면 **학교 → 1~4층 입체/배치도**를 사용한다. 지붕과 다른 층을 숨겨 이름이 가려지지 않도록 한다.
