# 5개 레이싱 월드와 공용 기록

2026-11-13. 학교 본래 구조는 유지하며 레이싱에서만 가상 도로를 표시한다. 1라운드는 기존 경로, 2~5는 고속도로·터널·옥상 고가교·종합 코스다. 모두 3바퀴이고 우승하면 다음 라운드를 해금한다. 이전 해금은 보존한다.

## 플레이 흐름

- 첫 항공뷰에서 라운드별 공용 TOP 10 확인. PC 오른쪽 패널, 모바일 접이식 패널. 보이는 동안 30초마다 갱신한다.
- 차량 선택 → 큰 5개 라운드 탭 → 실제 3D 미리보기 → 출전. 잠긴 코스도 자동 회전과 대표 구간 카메라로 볼 수 있다.
- 완주하면 개인 최고 기록을 저장하고 공용 순위 진입 여부를 확인한다. 진입 시 학년·반·별명 입력. 다음 기록부터 같은 참가자로 자동 등록한다. 차고의 참가자 변경 버튼은 다음 등록 때 새 별명을 받는다.
- 미션 하나 완료마다 스탬프 1개. 시작 화면·차고·미션 HUD에 안내하며 다음 자동차까지 남은 스탬프를 표시한다. 미션 결과에서 차고로 바로 이동할 수 있다.
- 해금·스탬프·개인 최고 기록은 같은 주소/기기/브라우저의 localStorage에 저장된다. 공용 순위는 서버에 저장된다. 쿠키 삭제, 다른 기기는 동일 참가자로 자동 인증되지 않는다.

## 서버 저장과 배포

- 기존 Node 22 서버에 `node:sqlite`를 사용한다. 외부 DB 라이브러리나 사진/대형 모델 추가 없음.
- 기존 Railway 서비스에 `/data` 영구 볼륨 연결. 자동 제공 `RAILWAY_VOLUME_MOUNT_PATH`를 읽어 `/data/racing/records.sqlite`에 저장한다.
- `관리도구/서버시작.mjs`가 볼륨 내 전용 폴더 권한만 준비한 뒤 UID/GID 1000으로 낮춰 웹 서버를 연다. HTTP 서버는 root로 실행하지 않는다.
- 볼륨이 없으면 공용 API는 503 안내를 반환한다. 휘발성 디스크에 운영 기록을 저장하는 것으로 위장하지 않는다. 기존 학교 탐험은 계속 사용할 수 있다.
- 로컬 테스트: `RACE_DATA_DIR`로 DB 폴더 지정 가능. 기본은 Git 제외 `output/race-data`. DB, WAL, SHM, 참가자 쿠키와 실제 기록은 Git에 커밋하지 않는다.
- 운영 볼륨은 사용량 과금 대상이며 단일 인스턴스에서 사용한다. 볼륨 백업/복구는 Railway에서 관리한다. 배포 시 볼륨 유지. 볼륨을 지우면 기록도 사라진다.

## API와 기록 정책

- GET `/api/racing/records?round=1` — 버전별·라운드별 TOP 10. 원시 참가자 식별자는 공개하지 않는다.
- POST `/api/racing/start` — 서버 발급 1회용 출발 토큰. 같은 사이트에서만 호출, HttpOnly/SameSite/운영 Secure 쿠키.
- POST `/api/racing/finish` — 실제 시간, 완주 경로 표본, 속도/순서/코스 범위/3바퀴 도착 확인.
- POST `/api/racing/submit` — 학년·반·별명 저장. 같은 기기/참가자는 더 빠른 기록으로 갱신. 트랜잭션에서 정렬 후 10위 밖을 삭제한다. 동률은 먼저 등록한 순서.
- 출발 토큰 만료 2시간, 사용한 토큰 재등록은 중복 기록을 만들지 않는다. 요청 크기 및 반복 호출 제한, 파라미터 SQL, 문자 제한 및 textContent 렌더링을 사용한다.
- `COURSE_VERSION`으로 경로가 다른 기록의 혼합을 막는다. 경로/성능 밸런스를 바꿀 때 버전 갱신 여부를 검토한다.
- 학생 계정 인증이나 서버 전체 물리 재생은 아니다. 클라이언트 조작에 대한 기본 검증이며 완벽한 부정행위 방지나 실명 확인을 보장하지 않는다.

## 검증

`입체코스완주검사.mjs`: 5개 코스 실제 물리 3바퀴, 경사/투영 연속성, 해금/PB 재시작 복원.

`입체코스AI검사.mjs`: 정지 플레이어가 있어도 AI 전원이 5개 코스 완주.

`공용기록서버검사.mjs`: 5개 코스 실제 물리 표본을 HTTP 서버로 검증, 14명 동시 제출, TOP 10, SQLite 재시작 복원, 잘못된 출처/시간/이름/만료/중복 차단.

Playwright `레이싱월드.cli.js`, `레이싱해금기록.cli.js`, `레이싱입체모바일.cli.js`: PC/모바일 UI, 잠금 미리보기, 키보드 주행, 우승 해금, 재접속, 기록 입력, 높은 도로 카메라, 반복 전환/가로 화면/학교 복귀. 기록 입력 UI 테스트는 결정적 응답을 사용하며 실제 서버 검증은 별도의 위 HTTP 검사에서 수행한다. 실물 휴대폰 GPU·스피커 확인과는 구분한다.
