# 4층 사진 반영 상태

## 적용 완료

- 웹 건물의 외곽 벽 접합부와 벽–천장 사이를 보강했습니다. 문과 네 계단은 유지했습니다.
- 6-1 앞 원본의 미리보기에서 확인한 하늘색 하부벽, 나무색 문·창틀, 신발장, 노란 바닥선과 천장 조명을 6학년 복도에 근사 마감으로 적용했습니다. 나머지 사진 각각의 공간 차이를 반영한 실사 결과는 아닙니다.
- 웹 상단의 **4층 6학년 복도** 버튼으로 바로 들어갈 수 있습니다.
- 교실 41곳의 문, 네 계단의 1~4층 왕복, 운동장 출입 검사 통과.
- 456개 위치의 시선 131,287개 표본에서 틈 누출 없음. 의도된 1층 출입문 제외. 모든 연속 위치를 검사한 것은 아닙니다.
- Blender 원본은 변경하지 않았으며 이번 보강은 웹에 적용했습니다.

## 원본 변환·사진 편집 완료

- 사용자가 제공한 X6 INSP 9장을 직접 읽어 360도 파노라마로 변환했습니다. 사용자에게 JPG 변환을 요청할 필요가 없습니다.
- 주 노출 렌즈 영상을 추출하고 로컬 FFmpeg v360으로 4096×2048 파노라마를 만들었습니다. 렌즈 화각 200도를 사용한 근사 투영이며 공장 보정 또는 광학 흐름 스티칭은 아닙니다. 일부 이음새 차이가 남아 있습니다.
- 기본 제공 image_gen으로 9장 모두 촬영자·휴대전화·셀카봉 흔적과 가려진 바닥을 편집했습니다. 결과물은 1774×887이며, 생성 영역과 일부 작은 세부는 실제와 다를 수 있습니다. 원본과 4K 변환본은 별도 보존했습니다.
- 웹에서 ‘4층 실사 360도’를 누르면 연결된 9개 촬영 위치를 둘러볼 수 있습니다. 마우스 드래그로 시점을 바꾸고 W/S 또는 이전/다음 버튼으로 이동합니다. Esc는 해당 위치 근처의 3D로 복귀합니다.
- 원본과 사진을 외부에 공개하거나 GitHub에 업로드하지 않았습니다.
