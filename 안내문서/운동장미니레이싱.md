# 운동장 미니레이싱

시작 화면의 **미니레이싱 · 나의 차고**에서 입장합니다. 기존 운동장 흙바닥에 흰 분말 라인기로 그린 듯한 경계선·출발선과 작은 안전콘을 더해 가상 코스를 만듭니다. 아스팔트나 중앙 잔디판으로 덮지 않습니다. 학교로 돌아오면 기존 운동장과 시설이 복원됩니다. 날씨 연동은 보류했습니다.

확장 코스는 운동장 가장자리에서 본관 1층 중앙현관·뒤문을 거쳐 후문 주차장까지 이어집니다. 중앙 통과 구간의 왕복 차선을 나누고 바닥의 흰 가루 화살표로 방향을 표시합니다. 연결 통로와 주행 구역은 레이싱에서만 열며, 자유탐험의 교실·복도·현관 배치는 유지합니다. 차체와 카메라는 지면 높이에 따라 움직이고 중앙현관에서는 추적 카메라를 낮춰 천장 아래로 통과합니다.

## 차량과 해금

기존 11대에 새 차량 7대를 추가해 총 18대입니다. 신규 수집 차량은 운동장 가장자리의 주차 구역에 있습니다. 기존 정문·후문 차량도 동일한 성능·해금 기준을 사용합니다.

| 누적 스탬프 | 해금 차종 |
| --- | --- |
| 0 | 클래식 세단, 시티 경차 |
| 3 | 투어링 SUV |
| 6 | 모닝 스타일 경차 |
| 10 | 투싼 스타일 SUV |
| 14 | 일렉트릭 GT |
| 18 | 랠리 세단 |
| 24 | Rock On 슈퍼카 2대 |
| 30 | 스포츠 투어러 |
| 36 | 오로라 하이퍼카 |
| 48 | 석암 챔피언 에디션 |

스탬프는 소비하지 않습니다. 기존 퀴즈·배달 미션을 하나 완료할 때마다 누적됩니다. 처음부터 할 수 있는 배송 미션은 기본 세단을 사용합니다. 잠긴 차량은 자유탐험의 F키와 터치 탑승 버튼, 레이싱 출발 모두 차단합니다.

`석암-RockOn-기록-v1` localStorage에 스탬프, 우승 횟수, 최고 통과 라운드를 저장합니다. 같은 기기와 브라우저, 같은 사이트 주소에서 유지됩니다. 브라우저 데이터 삭제·다른 브라우저·다른 주소 사이에는 공유되지 않습니다. 저장이 막힌 브라우저에는 현재 방문에서만 유지된다는 안내를 표시합니다. 기존 12단계 완주 최고기록이 있으면 최초에 12개를 인정합니다.

## 레이스

- 5개 라운드 모두 3바퀴, AI 3~5대. 1위로 다음 라운드를 엽니다. 통과한 라운드는 다시 선택할 수 있습니다.
- 초반 AI는 일반차, 중반은 SUV·GT·랠리카, 후반은 스포츠카·투어러·하이퍼카입니다. AI는 선택한 플레이어 차에 따라 속도를 따라 올리지 않습니다.
- 속도·가속·출발·코너링·접지·충돌 회복에 차이가 있습니다. 스포츠카는 모든 기본 차종보다 우수하며, 상위 보상 차는 더 강합니다. 게임용 성능이며 실제 제조사 제원이 아닙니다.
- 직접 핸들을 조작하는 주행입니다. 전진만 누르면 차량이 바라보는 방향으로 직진하며, 코너나 경계에서 트랙 방향으로 자동 정렬되지 않습니다. 경계에 부딪히면 직접 핸들을 돌리거나 후진해서 빠져나와야 합니다. 순서대로 체크포인트를 통과해야 한 바퀴로 인정되며, 역주행이나 중앙 가로지르기로 바퀴 수를 올릴 수 없습니다.
- 내 차가 매 바퀴를 완주할 때 책·의자를 새로 배치합니다. 횡단면마다 장애물은 하나이며 통과 공간을 남깁니다. 차량 바로 앞에는 재생성하지 않습니다.
- PC: W/위 전진, A D/좌우 핸들, S/아래 후진, Space 브레이크, Shift 부스트, R 코스로 복귀, Esc 일시정지. 모바일: 가속·후진·좌우 핸들·브레이크·부스트 버튼을 동시에 누를 수 있습니다. 복귀 버튼은 마지막으로 통과한 지점으로 돌아가며, 자동으로 차를 돌려주는 기능은 없습니다.
- 포커스 이탈과 백그라운드 전환은 자동 일시정지합니다. 엔진 소리는 기본 꺼짐이며 버튼으로 켭니다.

## 선생님과 함께 달리기

라운드를 시작하거나 재도전할 때마다 기존 학교의 6-1~6-7 담임선생님, 과학선생님, 교장선생님 중 3~5명을 무작위로 뽑아 AI 차량의 운전자로 배정합니다. 한 경기 안에는 같은 선생님이 중복 출전하지 않습니다. 교실에 있는 NPC를 옮기거나 수정하지 않으며 기존 외형을 사용한 레이싱용 운전자와 차량 위 이름표로 구분합니다.

AI 운전자에는 기존 얼굴·복장의 상반신을 재사용한 경량 모델을 사용합니다. 필요한 선수만 순서대로 불러오고 다시 출전하는 모델은 캐시를 재사용합니다. 차량의 이름표는 벽 뒤로 투시하지 않고 먼 거리에서는 숨깁니다.

각 라운드의 결과표는 **순위 / 선수 이름 / 차량 / 기록**을 함께 표시합니다. 마지막 5라운드에는 ‘최종 라운드 선수 순위’가 표시됩니다. 순위는 플레이어가 결승선을 통과한 시점에 결정하며 먼저 완주한 차량은 완주 기록, 아직 달리는 차량은 통과한 구간과 진행 거리로 정렬합니다. 미완주 차량은 가상의 완주 시간을 만들지 않고 ‘주행 중’으로 표시합니다.

선수 ID·표시 이름은 `웹학교/레이싱선수.mjs`에 있습니다. `웹학교/검사/레이싱선수검사.mjs`에서 기존 학교 NPC 목록과 일치하는지, 무작위 배정에 중복이 없는지, 순위와 실제 차량의 선수 정보가 일치하는지 검사합니다. 복귀 지점에 다른 차량이 있을 때에는 순간 이동으로 겹치지 않도록 기다리라는 안내를 표시합니다.

## 그래픽과 기존 기능 보호

Three.js 장면·렌더러를 그대로 사용합니다. 별도 엔진이나 대용량 자동차 모델·사진은 추가하지 않았습니다. 차량 패널, 유리, 휠, 램프, 그릴을 코드로 생성하며 반복 부품을 묶어 렌더링합니다. 레이스 장애물은 매 바퀴 새로 할당하지 않고 재사용합니다. 차고 차량 교체·학교 복귀 때 임시 차량 리소스를 해제합니다. 레이스 중에는 기존 학교 물리·교실 상세·교사 애니메이션 갱신을 멈춥니다.

선택한 남녀 학생은 차고와 레이스에서 운전석에 앉아 유리창 안으로 보입니다. 자유 탐험의 학생 모델과 앉는 동작을 재사용하며, 차체의 회전·경사에 맞춰 좌석 위치를 갱신합니다. 공유 학생 모델을 차량에 재부모화하거나 해제하지 않고 학교 복귀 때 운전 자세만 해제합니다.

디자인 참고: [기아 모닝 공식 디자인](https://www.kia.com/kr/vehicles/morning/features), [현대 4세대 투싼 히든라이팅](https://www.hyundaimotorgroup.com/ko/story/CONT0000000000003651). 차량은 특징을 참고해 만든 게임용 모델이며 제조사 원본 3D 모델은 사용하지 않았습니다.

```powershell
node 웹학교/검사/레이싱검사.mjs
node 웹학교/검사/레이싱통로검사.mjs
node 웹학교/검사/레이싱선수검사.mjs
node 웹학교/검사/운전검사.mjs
node 웹학교/검사/자동차속도검사.mjs
node 웹학교/검사/미션차량검사.mjs
node 웹학교/검사/스탬프미션검사.mjs
```

프로젝트 Playwright 세션에서 `웹학교/검사/레이싱PC.cli.js`, `웹학교/검사/레이싱모바일.cli.js`, `웹학교/검사/레이싱선생님.cli.js`를 실행합니다. 마지막 검사는 실제 운전자 모델 로딩과 최종 라운드 순위표를 확인합니다. 로컬 `?test=1` 진단은 운영 사이트에 노출되지 않습니다. 모바일 검증은 브라우저 터치 에뮬레이션이며 실제 휴대폰 발열·GPU 성능·스피커 출력은 별도 기기에서 확인해야 합니다.
