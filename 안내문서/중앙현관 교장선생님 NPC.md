# 중앙현관 교장선생님 NPC

- 1층 본관 중앙현관의 옆쪽 `(47, -2.8, 0)`에 마라토너 교장선생님을 추가했습니다. 기존 출입 통로는 유지합니다.
- 러닝 상·하의, 운동화, 선글라스, 윗부분이 열린 선캡, 오른손 메가폰을 입체 형상으로 표현했습니다. 현재 v5에서는 사용자가 선호한 이전 배포본의 얼굴 사진을 두 NPC에 다시 사용합니다.
- 현관 NPC는 제자리에서 숨쉬는 동작을 하고, 가까이 다가온 학생 쪽으로 몸을 돌립니다.
- 교장실 NPC의 정장과 교장실 안 이동 경로는 유지했습니다. 얼굴·목·뒷머리는 두 NPC가 같은 모듈을 사용합니다. 별도 검토 중인 Blender 전체 모델은 적용하지 않았습니다.
- 두 NPC에게 약 2.8m 이내로 다가가면 `행복하세요! 9월은 September!` 말풍선이 나타납니다. 소리 재생은 없습니다.
- 얼굴 v3에서는 눈꺼풀과 입술을 입체 표면으로 다듬고, 홍채·눈썹 결·미세 피부 질감과 볼 굴곡을 추가했습니다. 사진으로 만든 얼굴 스캔은 아니므로 실물과의 정확한 일치나 완전한 실사 표현을 보장하지 않습니다. 옷·머리카락·선글라스·선캡·메가폰·움직임은 변경하지 않았습니다.
- 후속 얼굴 v4에서는 타원형 기본 얼굴을 교체했습니다. MakeHuman의 CC0 인체 기본 메시에서 머리만 추출하고 중년 남성 형태, 볼·눈가와 미소를 조정했습니다. Blender에서 곡면을 다듬어 약 1.7만 정점의 얼굴로 만들었습니다. 코·눈꺼풀·입술·귀가 연결된 실제 입체 형상이며 얼굴 사진 텍스처는 없습니다. 기존 모자·머리카락·목 연결에 맞췄으며, 얼굴 밖의 복장·소품·행동·인사 문구는 유지합니다.
- v4 형상 데이터 및 출처는 `웹학교/외부도구/교장얼굴형상.mjs`, `교장얼굴형상-출처.txt`에 있습니다. 브라우저는 외부 모델 서비스에 접속하지 않습니다. [원저작자 자산 라이선스](https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.md)는 CC0이며 MakeHuman 프로그램 코드는 포함하지 않았습니다.
- 현재 v5: `교장선생님사진얼굴.mjs`에서 기존 `사진마감/교장실/교장선생님-얼굴.png`를 재사용합니다. 사진 파일 자체는 편집하지 않았습니다. 정면의 눈·코·입과 머리카락을 유지하고, 입체 표면에서 옆머리·뒷머리·목의 색으로 점진적으로 전환합니다. 사진 평면, 별도 목 원통, 겹치는 머리 덩어리 대신 연결된 두상 표면을 사용합니다. 사진에 없는 옆·뒤 모습은 추정 형태이며 얼굴 스캔은 아닙니다.
- 머리와 머리에 붙은 소품을 기존의 82%로 줄이고, 어깨·팔·손과 목깃을 성인 비율에 맞춰 조정했습니다. 정장 셔츠·넥타이·옷깃은 서로 다른 깊이에서 몸통 곡면을 따릅니다. 키는 정장 약 1.84m, 러닝복 약 1.82m입니다. 얼굴 사진은 NPC 생성 시 한 번 지연 로드하며 실패 시 기본 피부·머리 색으로 표시됩니다. v4 자산은 보존하지만 현재 런타임에서는 가져오지 않습니다.
- 다른 층, 벽이나 가구 너머, 화면 밖, 메뉴 및 항공뷰에서는 인사를 숨깁니다. NPC 몸통을 통과하지 못합니다.

## 승인된 피부·선글라스 마감 (2026-09-16)

사용자가 별도 3D 검토 화면을 승인하여 `교장선생님피부마감.mjs`를 두 NPC에 적용했습니다. 얼굴 사진의 넓은 색 변화와 명암을 줄이고 눈·입·주름을 유지했으며, 얼굴·귀·목·신체에 공통 피부색을 사용합니다. 턱 아래와 뒤통수에서 목으로 이어지는 곡면을 완화했습니다. 1층 NPC는 검정 머리와 옆눈까지 감싸는 불투명 선글라스를 사용합니다. 흰색 선캡, 메가폰, 정장, 배치 위치, 이동 및 인사는 유지합니다.

승인된 표시 버전은 `approved-skin-wrap-v6`입니다. 사용자 요청에 따라 커밋·푸시 및 기존 Railway 서비스 배포를 진행합니다. 배포 완료 여부는 배포 이력 문서와 공개 서비스 검증 결과를 확인합니다.
