# 교장실 실물형·귀여운형 캐릭터

2026-09-18 사용자 요청으로 로컬 비교 화면의 두 GLB를 기존 2층 교장실에 배치했습니다.

- 접근: 메뉴 → 교실·특별실 바로 가기 → 2층 교장실 → 이동. 입구에서 왼쪽 게시판 앞에 두 캐릭터가 있습니다.
- 실물형은 얼굴 형태를 부드럽게 다듬고 앞쪽 피부톤을 밝힌 v4입니다. 귀여운형은 기존 귀여운 시안입니다.
- 기존 몸·정장·얼굴·전체 비율을 보존하고 둘 다 기존 비교 화면과 같은 1.84m로 정규화합니다.
- 실물형 `(31.15, -1.90, 3.4)`, 귀여운형 `(31.15, -3.35, 3.4)`. 방 중앙을 향해 서 있으며 문과 가구 통로를 비워 둡니다.
- 기존 교장실 순찰 NPC 대신 두 모델을 표시합니다. GLB에 리깅과 애니메이션이 없어 고정 자세이며, 가까이 다가가면 기존 인사말이 표시됩니다. 중앙현관 마라토너 NPC는 유지합니다.
- 교장실 근처에서만 두 모델을 순서대로 불러오고 재입장 시 메모리에 보관한 모델을 재사용합니다. 실패하면 이름표로 안내하며 교장실 구역을 벗어났다 돌아오면 재시도합니다.
- 두 GLB는 약 56.7 MB이므로 최초 진입 시 연결 속도에 따라 로딩 시간이 필요합니다. 원본과 동일한 메시와 내장 텍스처를 사용하며, 별도 압축·리깅은 이번 범위에 포함하지 않았습니다.
- 파일: `웹학교/캐릭터모델/교장선생님-실물.glb`, `교장선생님-귀여운.glb`. 제작 출처는 같은 폴더의 `출처.md`에 있습니다.
