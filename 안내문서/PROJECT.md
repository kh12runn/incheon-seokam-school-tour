# 인천석암초등학교 3D 가상학교

배치도를 공간 관계의 1차 기준으로 사용하고, 실측값과 사진으로 점진 보정하는 Blender 기반 프로젝트다.

최신 범위는 사용자 추가 요청에 따라 ㄱ자로 연결된 두 동의 1~4층과 운동장까지 확장했다. 설계도면을 형태 기준으로, 2026 배치도를 현재 실명 기준으로 사용한다. 치수는 `공간자료/settings.json`의 `campus` 근사값이다. 원본 사진은 `사진보관/원본/`에서 수정·삭제·덮어쓰기하지 않는다.

표현 방식은 공간별 `3d`, `panorama`, `hybrid`를 허용한다. 360 사진은 단일 촬영점에서 정확한 파노라마로 취급하며 측정된 3D 기하로 간주하지 않는다.
