# 교무실 사진 세부반영

2026-09-30 공개 승인 API의 `2F_STAFF` 사진 12장을 직접 비교했다. 원본은 변경하지 않으며 `work/2F_STAFF-photos/`에만 보관한다. 사진에 보이는 재질과 가구 특징을 기존 Three.js 공간에 적용한 것으로, 실측 복원은 아니다. 방 크기와 가구 치수는 추정이다.

- 벽: 밝은 회백색의 미세한 표면 질감. 기존 벽 개구부를 유지한다.
- 바닥: 밝은 회백색 바탕에 흐린 얼룩무늬와 가는 사각 줄눈. 타일 간격은 약 60cm로 추정한다.
- 천장: 사각 흡음판 이음과 작은 점무늬, 직사각 조명, 에어컨 흡입 격자와 토출구.
- 업무석: 청회색 하부와 베이지 상부 파티션, 금속 이음, 낮춘 높이, 듀얼 모니터와 키보드 키, 전화기, 서랍 손잡이. 입구 왼쪽 벽 업무석 2개는 유지한다.
- 회의 공간: 사진처럼 하나로 이어 보이는 긴 목재 상판과 유리 덮개, 둥근 모서리·검정 테두리. 기존 탁자 충돌 상자 2개는 유지한다. 붉은 망사 등받이와 검정 좌판의 의자 8개, 흩어진 서류와 색 표지, 노란 격자 바구니, 필기구·펌프 용기·티슈를 반영했다.
- 파티션: 업무석 사이의 비어 보이던 구간을 같은 청회색·베이지 패널과 금속 이음으로 연결했다. 주 통로는 유지한다.
- 수납과 창가: 흰 수납장 문 이음과 손잡이, 냉장고 윗장, 싱크와 수전, 가전 세부, 책장과 파일, 녹색 콤비 블라인드와 창틀 손잡이·안전봉, 원통형 화분과 개별 잎.

사진 속 실명·문서 내용·CCTV 화면은 복사하지 않는다. 승인 대기 또는 비공개 사진은 확인 범위가 아니다.

## 확인

- `node 웹학교/검사/교무실연결문검사.mjs`: 사진 수, 마감, 가구, 통로 30/60/144 FPS, 연결문 왕복, 원본 데이터 불변성.
- `STAFF_DETAIL=1 node work/review-handoff.mjs`: PC 1100x760 / 모바일 390x700, 각 4개 시점, 캔버스 픽셀 및 페이지 오류 검사. 결과 `output/handoff-review/`.
- `node work/check-staff-live.mjs`: 실제 앱의 방 선택, 교무실 진입, 이동과 회전. 결과 `output/handoff-review/staff-live-checks.json`.

`renderInDetails` 표식은 탁자와 화분의 충돌 상자를 유지하면서 해당 물체의 곡면 형상을 별도로 표시하는 데 사용한다. 다른 방의 마감은 변경하지 않는다.
