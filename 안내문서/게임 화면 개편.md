# 게임 화면 개편

2026-09-10 로컬 작업. GitHub 커밋·푸시 및 Railway 배포는 하지 않았습니다.

- 실사 360도/교실 실제 사진 버튼, 전체 건물·층별 단면 선택, 항공뷰 회전 재생·멈춤 버튼 제거. 사진 파일과 기존 뷰어 소스는 보존하며 현재 게임에서는 뷰어를 불러오지 않습니다.
- 자동 항공뷰 위에 시작 화면 배치. 탐험 시작 → 남학생/여학생 선택 → 3인칭 탐험 순서 유지.
- 민트색 주요 버튼, 반투명 짙은 녹색 메뉴, 위치 표시, 미니맵과 실제 교실 방문 진행 표시로 UI 통일. 캐릭터 선택과 엘리베이터 창도 동일 스타일 적용.
- 오른쪽 위 메뉴 또는 Esc로 일시정지. 메뉴 안에서 본관/별관 1~4층, 교실·특별실, 6-4 교실로 이동. 설정에서 감도·마우스 잠금 없는 조작 지원.
- 탐험 중 메뉴의 닫기(X)/Esc/탐험 계속하기는 모두 즉시 탐험을 재개하고 마우스 잠금을 요청합니다. 항공뷰에서 메뉴를 닫으면 항공뷰를 유지합니다. (2026-09-10 메뉴 재개 추가 수정, 로컬 미배포)
- 브라우저가 잠금을 거절해도 화면 위에서 버튼을 누르지 않고 마우스를 움직여 시점을 바꿉니다. 이 대체 모드는 화면 가장자리까지만 움직일 수 있으며, 화면 한 번 클릭으로 잠금을 재시도할 수 있습니다. 설정의 명시적인 드래그 조작은 그대로 제공합니다.
- WASD 달리기, Space 점프, Z 인사, E 엘리베이터, 마우스 시점·휠 거리 조절은 유지. 학교 구조·가구·사진 마감은 이번 UI 작업에서 수정하지 않았습니다.

검증: 게임화면검사·육학년사반검사·이동검사·점프검사·삼인칭검사. 브라우저에서 자동 회전, 메뉴 일시정지, 여학생 선택, 4층 이동, 6-4 이동, 점프/인사, 390px 화면 메뉴 범위 확인. 브라우저 콘솔 오류 없음.
