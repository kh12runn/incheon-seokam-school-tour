# 실사 확장 전 현황 분석

후속 상태: 사용자가 첫 시범 공간으로 6-4 교실을 지정했습니다. 준비 등록 1개·활성 장면 0개이며 게임은 변경하지 않았습니다. 아래는 최초 확장 준비 당시의 분석/검증 기록입니다.

확인일: 2026-09-10. 이번 범위는 요청 STEP 1~6(분석·설계·폴더 준비)까지입니다. 게임 재작성, UI 재연결, Splat 제작, 텍스처 베이크, 배포는 하지 않습니다.

- Git HEAD `2ca740e`, 공개 코드 배포 기록 `d396cd6`. 이전 Esc/X 메뉴 재개 수정은 미커밋 로컬 변경입니다. 이번 작업은 이를 그대로 유지합니다.
- 수정 전 Git 추적 작업 파일 380개를 `모델/백업/실사확장준비-20260910-144530/`에 복사했습니다. 커밋만 복사한 것이 아니라 미커밋 수정까지 포함한 작업 파일 사본입니다. Git 이력 전체나 추적되지 않는 촬영 원본을 복제한 백업은 아닙니다. 촬영 원본은 기존 위치에서 변경하지 않았습니다.

### 기존 기능의 실제 상태

- WASD 달리기, 마우스 시점, 남/여 캐릭터, Space 점프, Z 인사, 3인칭 카메라 충돌, 네 계단 층간 이동, 층/실 바로가기, 미니맵, 엘리베이터, 자동 항공뷰가 현재 코드에 구현되어 있습니다. 본 작업에서는 변경하지 않습니다.
- **360 뷰어는 보존되어 있지만 현재 게임에서는 비활성입니다.** 앞선 사용자의 실사 버튼 제거 요청으로 `게임.mjs`가 이를 import하지 않습니다. 따라서 현재 Railway 최적화 묶음에도 파노라마 뷰어·사진이 들어가지 않습니다. 새 요구의 '유지'를 이유로 UI를 임의 복구하지 않습니다.
- 기존 4층 사진은 9개 촬영 지점입니다. `ready`, `position`, `heading`, 파일 해시가 있습니다. 근사 변환과 생성 보완을 거친 자료이며, 정확한 측량 영상 또는 개인정보 검수 완료 증명으로 취급하지 않습니다. 뷰어의 `open(fromPosition, manifestUrl)` / `onClose(entry)`를 향후 재사용할 수 있습니다.
- 반응형 UI와 포인터 드래그 처리는 있지만, **모바일 가상 조이스틱·터치 보행 전체가 구현된 것은 아닙니다.** 이번에 새 이동 시스템을 추가하거나 모바일 완성으로 표기하지 않습니다.
- README/기존 사용법에는 제거된 단면·실사 버튼, Shift 가속 등에 대한 과거 설명이 남아 있습니다. 현재 코드와 이 현황을 우선하며 과거 문서를 근거로 기능을 복원하지 않습니다.

## Blender / GLB 점검

설치된 Blender 5.2.1 LTS로 `--background --disable-autoexec`와 읽기 전용 검사 스크립트를 실행했습니다. 열려 있는 GUI 장면을 조작하거나 저장하지 않았습니다.

- 전체 학교 Scene: `Harness_Seokam_Campus`, 객체 2,212개(메시 1,803 / 글자 219 / Empty 189 / 카메라 1), 단위 미터·배율 1.
- 학교 메시의 UV 레이어 보유 0개, 이미지 텍스처 노드 0개. 즉시 사진을 베이크할 수 있는 UV 자산 상태가 아닙니다.
- 초기 3층 Scene `Harness_Seokam_3F` 및 기본 `Scene`도 저장되어 있습니다. 이들은 삭제하지 않습니다. 기본 Scene의 큐브 UV를 학교 UV로 잘못 계산하지 않습니다.
- 현재 원본에서 추출된 웹 구조는 상자 1,802개·글자 218개입니다. 지하 제외 등 exporter의 필터 때문에 Blender 전체 객체 수와 다릅니다.
- 기존 저장소에 학교 시각용/충돌용 GLB 로딩 경로는 없습니다. SuperSplat 패키지·실제 SOG 장면도 설치·등록되어 있지 않습니다.
- Blender 좌표/웹 물리는 Z-up `(x,y,z)`, Three.js 렌더 변환은 `(x,z,-y)`입니다. 웹 보정 이후 구조와 `.blend` 원본은 동일하지 않으므로 원본 GLB를 바로 충돌 모델로 쓰면 현재 학교와 어긋날 수 있습니다.

Texture Bake 적용 전에는 선택 구역 UV 작성과 별도의 '시각용 텍스처 메시' 출력/로드 경로가 필요합니다. 현재 상자 JSON 추출기를 덮어쓰거나 시각용 모델을 충돌용으로 통째로 사용하지 않습니다.

## Railway와 확장 영향

기존 URL은 `https://school-tour-production.up.railway.app/`입니다. 공개 배포 상태 설명은 `공간자료/공개재배포검사.json`의 직전 검증 기록 기준이며, 이번 작업에서 재배포하거나 원격 설정을 변경하지 않았습니다.

- 기존 Dockerfile은 웹 코드만 복사하고 도달 가능한 29개 파일을 수집합니다. `/splat/…/` 라우팅·SOG/GLB MIME·Viewer 의존 파일 수집은 아직 없습니다.
- 단순히 자산 폴더를 만들거나 JSON URL을 적어도 배포되지 않습니다. 검수된 SOG·GLB·뷰어·설정 파일만 명시적으로 포함하도록 추후 최소 변경이 필요합니다.
- `assets/splats/`는 이번 단계에서 Git 원본 제외 및 Railway 전체 제외를 적용했습니다. 실제 스캔·보존 원본을 외부 서비스에 올리지 않았습니다.
- GitHub 수동 Pages 워크플로는 과거 복사 방식을 유지하고 있습니다. 현재 기준 배포는 Railway이며, 이 작업에서 Pages나 자동 배포 설정은 변경하지 않습니다.
