# 12단계 퀴즈 스쿨런

시작 화면의 **퀴즈 미션 시작하기**에서 캐릭터를 고른다. 자유 탐험과 독립적으로 진행한다.

- 4가지 활동을 한 묶음으로, 총 3묶음·12단계. 각 묶음 안의 순서는 무작위다.
- **숨은 보물**: 지정된 학년의 교실 중 한 곳에서 보물을 찾아 선생님의 퀴즈를 푼다. 정답 교실은 안내에 공개하지 않는다.
- **교실 배달부**: 표시된 교실에서 물건을 직접 들어 선생님에게 전달하고 퀴즈를 푼다.
- **선생님 연결 미션**: 첫 선생님에게 힌트를 받은 뒤 다른 선생님에게 소식을 전하고 퀴즈를 푼다.
- **학교 배송 드라이버**: 물건 받기 → 지정 스포츠카 탑승 → 두 표지 순서대로 통과 → 정차 → 하차 → 물건 전달. 후문 주차장과 정문 쪽 운동장 코스를 번갈아 사용한다.
- 물건·대화는 **R / 화면 버튼**, 문·차량은 **F / 화면 버튼**, 운전은 **WASD / 터치 조이스틱**. 뒤에 있는 배송 표지는 후진으로도 통과할 수 있다.
- 미션 중에도 엘리베이터 앞에서 **E / 엘리베이터 타기**로 1~4층을 이동한다. 선택 창과 이동 중에는 타이머가 멈추며, 현재 미션·스탬프·들고 있는 물건은 유지한다. 메뉴의 층·교실 바로 가기는 계속 제한한다.
- 일반 단계 최소 4분, 대화 연결 최소 5분, 차량 배송 최소 8분. 실제 보행 경로와 아바타 속도에 따라 더 긴 시간을 준다. 메뉴·백그라운드·근처 선생님 모델 로딩 중에는 타이머가 멈춘다.
- 한 게임에 퀴즈 9개(영어 5, 상식 4), 차량 배송 3개. 첫 묶음은 기초 문제, 이후에도 기존 6학년 수준의 문제 범위를 유지한다. 질문·학년·교사·교실 추첨 이력은 기존 저장 방식을 재사용한다.
- 예전 4단계 최고 기록과 섞이지 않도록 12단계 기록은 별도 저장한다.

## 구현 및 검증

`스탬프미션.mjs`가 상태 전환·완료 조건을 관리한다. `미션배송.mjs`는 차량과 코스, `미션경로.mjs`는 실제 충돌·계단에 맞는 실내외 보행 경로를 정의한다. 기존 차량·교사·교실 모델을 그대로 재사용한다. 소품·배송 표지는 작은 기본 도형이며 새 이미지/GLB는 없다.

- `npm run test:mission`: 144단계 시뮬레이션, 문제 난이도·추첨·물건 전달·대화·차량만 체크포인트 인정·정차/하차·일시정지.
- `node 웹학교/검사/미션차량검사.mjs`: 두 코스의 실제 차량 물리, 탑승·왕복·정차·하차·배송 위치까지 보행.
- `웹학교/검사/스탬프미션브라우저.cli.js`: PC 12단계 완료·재도전·자유 탐험 복귀. 교실 간 위치 이동은 로컬 테스트 훅으로 단축하고, 차량은 실제 키보드 입력으로 운전한다.
- `웹학교/검사/스탬프미션모바일.cli.js`: 모바일 에뮬레이션에서 첫 묶음 4종을 터치·조이스틱으로 검증한다. 실기기 검사는 별도다.
- `node 웹학교/검사/배포검사.mjs`: 운영 번들, 무손실 자산 압축, 캐시 및 서버 경로 검증.

테스트 이동 훅은 localhost의 `?test=1`에서만 제공되며 운영 사이트에서는 제공하지 않는다.
