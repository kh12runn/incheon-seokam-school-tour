# 기타 촬영 사진

관리자 사진 업로드의 본관·별관 옆에서 **기타**를 선택합니다. 층이나 교실을 고르지 않아도 됩니다.

“촬영한 위치가 어디인지 설명해주세요”에 위치를 입력하고 사진을 올립니다. 예: `3학년 4반 앞 계단`, `별관쪽 운동장`. 설명은 1~300자이며 한 번에 올리는 사진에 동일하게 붙습니다. 서로 다른 위치는 나누어 업로드합니다.

- 고정 공간 ID: `OTHER_MISC`, 건물 구분: `OTHER`, 층·좌표: 미지정.
- 비공개 GitHub 저장 경로: `school-assets/uploads/기타/OTHER_MISC/`.
- 사진별 `locationDescription`, `requiresLocationConfirmation: true`를 catalog와 manifest에 보존합니다. 기존 사진 설명을 새 업로드 설명으로 덮어쓰지 않습니다.
- 기존처럼 업로드는 pending으로 저장되며, 승인 전 사진과 설명은 공개 assets API에 노출되지 않습니다.
- 승인된 사진과 설명 조회: `/api/rooms/OTHER_MISC/assets`.
- **자동 모델 반영 없음.** 사용자가 반영을 요청하면 사진별 설명과 기존 지도를 대조합니다. 위치를 확실히 특정할 수 없으면 사용자에게 먼저 묻고, 답변 전에는 임의로 교실·복도·계단 위치를 지정하지 않습니다.

기존 로그인, 휴대폰 이미지 변환, 다중 업로드, 승인 절차와 Railway 환경변수는 그대로 사용합니다.
