# 교실별 사진 반영 원칙

사용자 요청: 기본 형태는 6-4와 유사하게 유지하되, 사진이 들어오면 각 반의 고유한 특징을 반드시 반영한다. 모든 교실을 6-4의 복제품으로 만들지 않는다. 교실 내부만 보아도 어느 반인지 구분할 수 있게 한다.

## 현재 반영 범위

2026-09-14 갱신: 6-6은 휴대폰 사진 6장을 확인하여 전용 디테일을 적용했습니다. 6-4와 6-6을 제외한 나머지 23개 본관 일반 교실은 기존 임시 구성을 유지합니다. 상세 내용은 6-6 교실 사진반영.md를 참고하세요. 아래는 공통 기준을 처음 적용할 때의 범위입니다.

- 본관 일반 교실 25개 중 기존 사진 반영 6-4는 그대로 보존. 나머지 24개에 기본 실내 배치 추가.
- 별관 모든 교실, 본관 특별실, 복도, 계단, 원본 Blender와 학교구조.json은 변경하지 않음.
- 6-4 참고 칠판·교탁·책장·사물함·천장 조명·책상/의자 24석 적용. 실제 좌석 수를 확인한 것은 아니며 모든 미촬영 교실의 좌석 수와 가구 배치는 임시 근사값.
- 교실 너비에 맞춰 배치, 좁은 8m 교실은 소폭 축소하고 넓은 20m 교실에서는 가구 자체를 두 배로 늘리지 않음. 4-3은 복도 방향에 맞춰 좌우 창가/수납 방향 반전.
- 각 반 고유 이름·그림 주제·게시물 구성·하부벽/사물함/일부 의자·정리바구니 색으로 구분. 이 차이는 사진에서 확인한 사실이 아니라 임시 식별용 디자인이며 게시판에도 표시.

## 다음 사진을 받았을 때

1. 해당 반의 앞·뒤 원본을 모두 확인하고 현재 배치와 대조한다. 학생·교사·촬영자, 이름표와 개인 게시물 등은 공개 자산에 남기지 않는다. 원본은 보존한다.
2. 칠판 종류와 위치, 화면·교탁, 책상 수·짝/모둠 배열·의자 색, 사물함 개수·색·위치, 게시판의 색·구획·장식, 책장과 정리함, 창·커튼·문, 벽·바닥·조명, 기타 고유 물건을 항목별 기록한다.
3. 확인된 사항과 가려져 확인할 수 없는 사항을 구분한다. 알 수 없는 수량이나 게시판 문구를 실제 사실로 만들어내지 않는다.
4. 사진이 있는 반에서는 사진의 특징이 임시 테마보다 우선한다. 근거 없는 임시 장식은 사진과 충돌하면 제거한다. 단순히 학급 이름이나 색만 바꾸고 끝내지 않는다.
5. 공통 골격은 유지하면서 해당 교실의 변경사항만 별도 적용한다. 다른 반, 별관, 특별실 또는 6-4까지 일괄 수정하지 않는다.
6. 새 가구의 충돌, 출입문 폭, 책상 사이 통로, 바로가기 위치, 카메라 충돌을 다시 검사한다. 다른 교실의 boxes/colliders가 바뀌지 않았는지 비교하고 해당 반 앞·뒤 시점으로 화면 검수한다.

- 웹학교/육학년사반.mjs 및 육학년사반표현.mjs: 실제 사진을 받은 6-4의 전용 적용부. 기존 출력 유지.
