# 전체 학교 모델 확인 — 최신

**걷기 기능 활성화:** 학교 탭의 `선택한 층 걷기 시작`. WASD 이동, 마우스 시점, ESC 또는 오른쪽 클릭 종료. 걷는 중 숫자 1~4를 누르면 해당 층 본관 복도에서 다시 시작한다. 눈높이·속도는 settings.json을 따른다. 벽·창문·바닥 바깥을 차단하며 교실 문 개구부로 통과할 수 있다. 계단은 아직 층간 보행용으로 완성되지 않아 진입을 차단한다. 현재 기능 파일은 `모델/실행도구/campus_walk.py`이며 실행용 CMD가 자동으로 등록한다.

프로젝트 폴더의 `학교_3D_열기.cmd`를 더블클릭하면 최신 모델과 보기 버튼을 함께 연다. 현재 장면은 `Harness_Seokam_Campus`이다. **N → 학교 → 학교 전체 입체 보기 / 1~4층 입체 / 1~4층 배치도**를 사용한다. 마우스 휠 누르고 드래그하면 회전한다.

ㄱ자로 연결된 두 동의 1~4층과 운동장을 모델링했다. 현재 공간명은 `안내문서/ROOM_NAMES.md`, 엑셀에서 열 수 있는 목록은 `공간자료/room_names.csv`이다. 각 층 내 걷기는 지원하며 계단으로 직접 오르내리기는 미지원이다. 예전 단일층 걷기 버튼을 전체 모델용으로 교체했다.

비교 분석: `안내문서/PLAN_COMPARISON.md`. 결과: `결과물/미리보기/campus-overview.png`, `campus-1F-names.png`~`campus-4F-names.png`.

아래 내용은 이전 단일층 프로토타입의 기록이며 최신 모델 조작에는 위 안내를 사용한다.

# 이전 모델 기록

결과 파일: `모델/school_master.blend`. 현재 Blender에는 `Harness_Seokam_3F` 장면이 열려 있다.

화면 오른쪽 N 사이드바의 **학교 → 전체 배치 보기 / 복도 걷기** 버튼을 사용한다. 걷기는 WASD, 마우스 시점 회전, ESC 종료다. 속도는 초기 1.25m/s, 눈높이는 1.6m이다. 현재 세션에서 버튼이 등록되어 있다. Blender를 완전히 재시작한 경우 동봉된 `walk_preview.py`를 다시 실행해야 하며 자동 실행은 설정하지 않았다.

정지 화면: `결과물/미리보기/3F-overview.png`, `3F-corridor.png`.

현재 구현은 본관 3층 공간 골격, 문 개구부, 추정 창문, 계단 위치 표시, PhotoPoint, 두 카메라다. 계단 보행과 다른 층 연결은 미구현이다. 실측 비율과 사용자 체감 이동감은 사용자 확인 대기다. 3DGS 학습·360 투영은 수행하지 않았다.

복도 폭 2.8m, 교실 기본 크기 8×7m, 층고 3.2m, 문 폭 0.9m는 전부 임시 추정치다. 원본 INSP의 촬영 층·위치는 미확인이다.

Facebook 이동 참고 영상은 접근 실패로 분석하지 못했다. 현재 WASD와 눈높이는 Master Specification의 기본값을 사용한다.
