# 학생 Meshy 캐릭터

2026-09-19 기준, 시작 화면에서 선택할 남학생·여학생을 각각 실사풍과 귀여운형으로 제작했습니다. 사용자 요청에 따라 준비한 4종 기준 이미지를 Meshy API의 이미지→3D 생성, 휴머노이드 리깅, 애니메이션 생성으로 처리한 결과입니다. 실사풍도 생성 캐릭터이며 실제 학생을 스캔한 모델은 아닙니다.

앱에서는 원본의 금속·발광 재질을 비금속 무광 재질로 조정합니다. 2026-09-19 머리의 밝은 UV 경계가 흰머리처럼 보이는 현상을 보정하기 위해 머리카락 면을 분리하고 원래 색에 맞춘 짙은 무광 재질을 적용했습니다. 얼굴과 섞인 경계는 피부색 검사로 제외합니다. 형상·UV·텍스처·관절·애니메이션 데이터와 전체 삼각형 수는 원본과 동일합니다. 제작 스크립트와 원본 백업은 작업공간 `output/student-characters/fix-hair.mjs`, `before-hair-fix/`에 있습니다. Meshy API 재생성 없이 수행했습니다.

## 앱 연결과 캐시

학생의 목표 키는 `STUDENT_HEIGHT=1.4`입니다. Meshy의 기본 자세로만 1.65m에 맞추면 대기 애니메이션에서 실제 키가 1.82~1.86m로 늘어나 성인 교장 모델(1.84m)과 비슷해지는 문제가 있었습니다. 이제 대기 동작 11개 시점의 실제 스킨 정점 범위를 측정해 전체 모델을 균일하게 축소하고 발 위치를 보정합니다. 머리·몸의 원래 비율, 텍스처와 관절 동작은 유지합니다. 카메라 시선 높이, 인사 표시, 선택 화면 구도도 목표 키를 따릅니다.

`node 웹학교/검사/학생키검사.mjs`는 실제 GLB의 대기 동작 101개 시점을 검사합니다. 네 학생의 머리 높이 1.4008~1.4026m, 발 높이 오차 약 1cm 이내를 확인했습니다.

크기 보정 배포 `9c6cf457-0469-4342-8391-9eb1616e7ad9` SUCCESS. 데스크톱·모바일에서 선택·이동·점프·인사·교장실 진입을 확인했고, 공개 학생 런타임·게임 카메라·선택창 코드 해시가 수정본과 일치합니다. `공간자료/학생비율측정-20260919.json`, `학생비율화면검사-20260919.json` 참고.

`웹학교/학생캐릭터.mjs`에서 선택 ID를 GLB에 연결합니다. 요청한 모델의 로딩 Promise를 종류별로 메모리 캐시하고, 실패하면 캐시에서 제거하여 재시도할 수 있게 합니다. 미리보기와 플레이 캐릭터는 뼈대를 따로 복제하여 자세가 서로 영향을 주지 않도록 합니다. 기존 저장값 `boy`·`girl`은 각각 귀여운형으로 연결합니다.

달리기·점프의 위치 이동은 앱의 이동·충돌 처리에 맡기고, 애니메이션의 루트 이동을 정리하여 캐릭터가 이중으로 이동하지 않게 합니다. 이 문서의 자산 완성과 공개 서비스 반영은 별개이며, 공개 배포 성공 및 실제 동작 검증은 최종 배포 기록에서 확인합니다.

## 제작 기록과 연결

작업공간의 `output/student-characters/optimization-report.json`에 파일 크기·스킨·클립·텍스처 검사 결과가 있고, 같은 폴더의 `meshy-tasks.json`에 생성 작업 기록이 있습니다. 작업 기록에는 만료되는 다운로드 URL이 포함될 수 있으므로 공개 문서에 복사하지 않습니다. 이번 API 잔액은 18,070에서 17,862로, 총 208 크레딧을 사용했습니다.
