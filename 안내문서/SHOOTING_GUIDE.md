# 촬영 가이드

1. `촬영사진_넣는곳`에서 층·공간 이름을 확인한다. 전체 목록은 `공간자료/촬영폴더_목록.csv`, 위치 설명은 `안내문서/계단과 복도 위치 안내.md`다.
2. 긴 복도는 한 지점 사진보다 일정한 높이로 천천히 이동한 연속 INSV 영상을 우선한다.
3. 시작점과 끝점을 배치도에 표시하고, 계단·교차점·출입문에서 추가 촬영한다.
4. 사람, 움직이는 물체, 강한 역광을 줄이고 렌즈를 깨끗하게 유지한다.
5. 원본은 해당 `촬영사진_넣는곳` 폴더에 여러 장 넣고 수정하지 않는다. 날짜별 하위 폴더도 가능하다. 기존 `사진보관/원본/`는 이전 원본 보관용이며 두 곳에 중복 저장할 필요는 없다. 내부 처리 경로는 `공간자료/spaces.json`의 `intakeFolder`와 `photoFolder`로 연결한다.
6. 학생 얼굴, 차량 번호판, 문서와 게시물의 개인정보가 포함되지 않도록 확인한다.

첫 검증은 교실 하나와 문 앞 복도로 시작한다. 한 자리의 360 사진 한 장은 파노라마용이며, 자유 시점 복원에는 여러 위치에서 겹치게 촬영한 자료가 필요하다. 사진을 넣기만 하면 자동으로 학습·반영되는 것은 아니다.

계단 이름의 앞/옆/사이는 2026 교실배치도 PDF의 인접 실 기준이다. 본관 중앙 계단은 4층 6-3 앞, 3층 5-3 앞, 2층 교무실 앞, 1층 본관 출입구 뒤로 정정했다. 별관 1층 두 지점은 출입구만 표시되어 있어 계단 위치를 먼저 확인한다. 올라가는 구간은 아래층의 `02_…올라가는구간`에 저장한다. 화장실은 기본 촬영 제외다.

사진과 영상은 `.gitignore`로 공개 Git 업로드에서 제외한다. GitHub 웹에 직접 업로드하면 이 제외 규칙이 적용되지 않는다. 공개 전 개인정보 검토는 별도로 필요하다.
