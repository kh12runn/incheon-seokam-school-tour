# 교장선생님 말풍선 퀴즈

GitHub `0e38ac4`의 기존 학생·교장선생님 모델을 유지합니다.

- NPC 가까이 다가가면 머리 위 작은 말풍선에 무작위 월 문제와 중복 없는 보기 4개가 표시됩니다. 별도 팝업·배경 가림·탐험 일시정지가 없습니다.
- PC는 숫자 1~4, 모바일은 보기 터치로 선택합니다. 마우스 잠금이 없는 상태에서는 클릭도 가능합니다. 기존 마우스 잠금을 강제로 풀지 않습니다.
- 정답은 ‘참 잘했어요~’, 오답은 ‘다시한번 생각해보세요’. 틀린 보기를 제외하고 재도전할 수 있습니다.
- NPC에게서 약 4.2m 이상 멀어지면 종료되고 재접근 시 새 문제가 나옵니다. 화면 밖·벽 너머·다른 층·메뉴 중에는 숨겨집니다.
- 교장실의 인접 두 모델은 한 번의 만남으로 묶어 연속 출제를 방지합니다.

검사: `node 웹학교/검사/월영어퀴즈검사.mjs`, `node 웹학교/검사/월영어퀴즈실행.mjs`, `node 웹학교/검사/배포검사.mjs`.

브라우저 검사 실행기는 `PLAYWRIGHT_MODULE`, `QUIZ_BROWSER`, `QUIZ_BASE_URL`(기본 http://127.0.0.1:8085)을 지원합니다. GPU 없는 환경에서는 `QUIZ_LIGHTWEIGHT=1`로 검사 브라우저에서만 장면 그리기·환경광 생성을 생략합니다. 게임 데이터·모델 로딩·충돌·입력·DOM은 실제 코드를 실행하지만 전체 3D 렌더링 성능 검증은 아닙니다. 검사 캡처는 `결과물/퀴즈검사/`에 저장됩니다.
