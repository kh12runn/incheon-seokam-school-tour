# 교장선생님 말풍선 퀴즈

교장실의 단일 교장선생님과 중앙현관의 러닝복 교장선생님에게 같은 퀴즈가 적용됩니다.

- NPC 가까이 다가가면 머리 위 작은 말풍선에 무작위 월 문제와 중복 없는 보기 4개가 표시됩니다. 별도 팝업·배경 가림·탐험 일시정지가 없습니다.
- PC는 숫자 1~4, 모바일은 보기 터치로 선택합니다. 마우스 잠금이 없는 상태에서는 클릭도 가능합니다. 기존 마우스 잠금을 강제로 풀지 않습니다.
- 정답은 ‘참 잘했어요~’, 오답은 ‘다시한번 생각해보세요’. 틀린 보기를 제외하고 재도전할 수 있습니다.
- NPC에게서 약 3.05m 이상 멀어지면 문제·정답 결과·시도 횟수가 초기화되고, 2.8m 이내로 재접근하면 새 문제가 나옵니다. 화면 밖·벽 너머·다른 층·메뉴 중에는 숨겨집니다.
- 같은 교장선생님 주변에서 움직임이 흔들려도 문제가 연속으로 다시 열리지 않습니다.

검사: `node 웹학교/검사/월영어퀴즈검사.mjs`, `node 웹학교/검사/월영어퀴즈실행.mjs`, `node 웹학교/검사/배포검사.mjs`.

브라우저 검사 실행기는 `PLAYWRIGHT_MODULE`, `QUIZ_BROWSER`, `QUIZ_BASE_URL`(기본 http://127.0.0.1:8085)을 지원합니다. GPU 없는 환경에서는 `QUIZ_LIGHTWEIGHT=1`로 검사 브라우저에서만 장면 그리기·환경광 생성을 생략합니다. 게임 데이터·모델 로딩·충돌·입력·DOM은 실제 코드를 실행하지만 전체 3D 렌더링 성능 검증은 아닙니다. 검사 캡처는 `결과물/퀴즈검사/`에 저장됩니다.

## 2026-09-22 산책 적용

- 공동작업자의 최신 `288e260` 기준: 교장실 NPC 한 명, 183cm 신체, 중앙현관과 동일한 얼굴, 순환 인사말과 학생 선택 구성을 유지합니다. 원본 GLB는 변경하지 않습니다.
- 교장실은 가구 사이 빈 통로와 창가, 중앙현관은 출입 통로 안쪽을 약 0.48m/s로 산책합니다. 방향을 먼저 바꾼 뒤 천천히 출발하며 구간마다 잠시 쉽니다.
- 플레이어가 약 3.1m 안에 접근하면 멈춰 바라봅니다. 멀어지면 남은 경로를 다시 걷습니다. 메뉴·항공뷰·다른 층에서는 일시정지합니다.
- 기존 정장 메시·얼굴·UV를 보존하는 9관절 보행 리그와 러닝복 팔·무릎 관절을 사용합니다. 말풍선과 몸 충돌 위치도 실제 NPC 이동 위치를 따릅니다.
- 검사: `교장산책검사.mjs` 32,000 프레임 충돌·경로·정지 확인, `교장보행화면검사.mjs` 실제 WebGL 보행 자세, `월영어퀴즈실행.mjs` PC/모바일 및 실제 이동·재출제 확인.
