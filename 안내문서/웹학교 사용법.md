# 웹 학교 사용법

`학교_웹_열기.cmd` 실행 → 브라우저에서 `학교 탐험 시작하기`를 누릅니다. 서버를 실행한 창은 사용하는 동안 열어두세요. Node.js가 필요하고 Blender는 실행하지 않아도 됩니다.

첫 화면은 학교 전체를 도는 자동 항공뷰입니다. 사용자 요청에 따라 시스템의 동작 줄이기 설정과 관계없이 로딩 직후 회전을 켭니다. 상단에서 회전을 멈추거나 다시 켤 수 있고, 직접 드래그/확대한 뒤에는 6초간 자동 회전을 쉬어갑니다. 회전은 실제 경과 시간에 맞추며 예전 `?photo=1` 주소도 전체 보기로 시작합니다.

상단 **본관·별관 층 이동**에서 본관/별관 1~4층을 선택하면 해당 층 중앙 계단 앞 복도(중앙현관 이동 기준점)로 이동합니다. 곧바로 WASD로 걸을 수 있고 마우스 드래그로 시점을 바꿉니다. 모델에 층마다 독립된 현관실을 새로 만들지는 않았습니다. **전체 건물 / 1~4층 단면** 메뉴는 이동이 아닌 관찰용입니다.

입장 안내창은 작게 줄였고, 상세 조작·교실 바로 가기·사진 반영 범위는 펼쳐볼 수 있습니다.

| 조작 | 기능 |
|---|---|
| W / S | 앞 / 뒤 |
| A / D | 왼쪽 / 오른쪽 |
| 마우스 | 시선 돌리기 |
| Shift | 빠르게 이동 |
| ESC | 일시정지하고 메뉴 사용 |
| V | 학교 전체 보기 |
| R | 1층 본관 복도 출발점 복귀 |

걷기 시작 시 마우스가 화면에 고정됩니다. 브라우저가 허용하지 않으면 드래그 시점으로 자동 전환됩니다. 이 경우 마우스 버튼을 누른 채 드래그해 시선을 돌리고 WASD로 이동합니다. 잠금 방식으로 돌아가려면 걷기 시작 버튼을 다시 누르세요.

## 계단과 충돌

지도에서 보라색이 계단입니다. 입구 왼쪽 계단을 따라 올라가고 중간참에서 오른쪽으로 돌아 나머지 계단을 올라가면 위층 복도로 나옵니다. 내려갈 때는 반대 경로를 사용합니다. 본관 두 곳과 별관 두 곳 모두 1~4층을 연결합니다. 별관 1층의 정확한 현장 위치 등은 검증 전이므로 구조는 근사 모델입니다.

계단 표면은 보이는 디딤판 아래의 완만한 경사로로 계산해 덜 흔들리도록 했습니다. 이동을 짧은 구간으로 나눠 벽·창문·계단 옆벽과 충돌을 확인합니다. 바닥을 확인하여 계단 구멍으로 떨어지지 않게 합니다. 점프와 자유 비행은 미지원입니다. 전체 보기는 플레이어 이동과 별개의 관찰 카메라입니다.

본관 현관에서 운동장으로 나갈 수 있습니다. 앞 구령대는 막혀 있으므로 옆으로 돌아갑니다. 교실 41곳은 문 출입 경로를 검사했습니다. 일부 특별실의 원본 출입 구조는 여전히 단순하므로 메뉴의 실 바로 가기를 함께 사용할 수 있습니다.

## 4층 실사 360도 보기

상단 **4층 실사 360도** 버튼을 누르면 제공된 INSP에서 직접 변환·편집한 9개 촬영 위치를 볼 수 있습니다. 마우스 드래그로 시점을 바꾸고, W/S 또는 이전·다음 버튼으로 위치를 이동합니다. A/D는 좌우 회전, 휠은 확대·축소입니다. Esc 또는 **3D 걷기로 돌아가기**를 누르면 해당 촬영 위치 근처로 돌아옵니다.

촬영자·휴대전화와 가려진 바닥은 AI 편집했습니다. 웹 사진은 1774×887이고 원본·4K 변환본도 따로 보존합니다. 원본 렌즈의 근사 투영이므로 작은 이음새 차이가 있고 생성한 부분은 실제 모습과 다를 수 있습니다. 360도 촬영 지점을 연결한 방식이며 자유 시점 3DGS나 메시 실사 UV 텍스처화는 아닙니다.

기존 3D 걷기에서는 벽·천장 틈을 보강하고 4층 복도에 사진 참고 마감을 추가했습니다. 본관 1~3층 복도에도 같은 하늘색 하부벽·목재 문/창틀·노란선·바닥 줄눈·조명을 근사 적용했습니다. 신발장은 본관 1~2층에 없고 3~4층은 학급당 7열×3행=21칸 한 세트입니다. 목재 결·바닥 입자·표면 거칠기·반사는 코드로 표현한 근사 재질이며 실제 UV 사진이나 실측 복원이 아닙니다. 별관 가구/재질과 원본 Blender 파일은 변경하지 않았습니다. 전체 장면의 톤 매핑은 조정되었습니다.

## 창가 신발장과 흙 운동장

본관 3~4층 신발장은 전부 실제 창문이 있는 구간으로 옮겼습니다. 학급당 7열×3행을 유지하고 계단·화장실·연수실 앞은 비웠습니다. 교실 바로 맞은편에 창이 없으면 가까운 창가에 이름표를 달아 배치했습니다. 1~2층 신발장은 없습니다.

운동장은 ㄱ자 건물 안쪽의 원래 위치에 있습니다. 운동장을 향한 본관·별관 교실의 창문을 통해 3D 흙 운동장을 볼 수 있습니다. 복도에서 운동장을 보이게 하는 요청은 취소되었습니다. 유리는 투명하지만 통과할 수 없습니다. 햇빛 그림자, 목재 결·바닥 입자·흙의 얼룩과 거칠기는 사진을 참고한 코드 기반 임시 표현입니다.

복도 창가 방향으로 옮겼던 임시 운동장과 부지 확장을 취소하고 원래 운동장·부지 좌표를 복구했습니다. 골대와 바닥선도 안쪽 운동장으로 복귀했습니다. 교실 배치는 유지했습니다. 운동장 흙 질감과 주변 세부는 후속 운동장 사진으로 다시 맞출 예정이며, 설정/형상은 `웹학교/운동장.mjs`에 분리되어 있습니다.

## 골대 방향과 본관 뒤 주차장

축구 골대 2개는 배치도 기준 운동장 위·아래 끝에서 서로 마주 보며, 경기장 선도 같은 방향입니다. 운동장은 ㄱ자 건물 안쪽을 유지합니다.

본관 뒤에는 아스팔트 바닥, 16개 주차면, 서쪽 진입로와 주차 차량 4대를 간이 배치했습니다. 실제 주차장 실측/사진을 반영한 것은 아닙니다. 진입 통로로 걸어갈 수 있고 차량은 통과할 수 없습니다. 자동차 운전 기능은 없습니다.

## 엘리베이터 이용

본관 끝 ㄱ자 접합부, 4-3 교실 오른쪽 코너에 1~4층 승강로와 문을 추가했습니다. 각 층 문 앞에서 **E** 또는 화면의 호출 버튼을 누르고 층을 선택하면 해당 층 엘리베이터 앞 복도로 이동합니다. 이는 짧은 화면 전환을 이용한 간이 이동이며 문 개폐·카 내부 탑승·연속 승강 애니메이션은 아닙니다. 닫힌 문과 승강로 벽은 통과할 수 없습니다.

로컬 서버는 이 컴퓨터에서만 접속하는 주소로 실행됩니다. Railway 배포에서는 지정된 `PORT`로 외부 접속을 받습니다. 원본 사진·배치도 PDF·Git 관리 파일은 웹 서버에서 접근할 수 없습니다. 2026-09-10 사용자 요청으로 현재 3D 작업물과 편집 완료 웹용 사진 9장의 공개 배포를 승인받았습니다.

검증: 네 계단 1→4→1층, 각 층 복도·벽·창문·41개 교실 문·운동장 왕복을 검사했습니다. 브라우저에서도 실제 키 입력으로 1층→중간참→2층, 마우스 회전, ESC 정지를 확인했습니다.
