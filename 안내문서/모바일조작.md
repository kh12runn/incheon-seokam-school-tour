# 모바일 학교 탐험

- 왼쪽 아래 가상 조이스틱을 원하는 방향으로 밀면 달립니다. 손을 떼면 멈춥니다.
- 오른쪽 화면을 손가락으로 밀어 시점을 돌립니다. 이동 조이스틱과 동시에 사용할 수 있습니다.
- 오른쪽 아래 점프·인사 버튼을 사용합니다. 이동·시점·점프 동시 입력을 지원합니다.
- 엘리베이터 앞에서는 화면의 ‘엘리베이터 타기’를 누릅니다. 층·교실 바로 가기는 위쪽 메뉴에 있습니다.
- 시작 항공뷰는 한 손가락으로 회전, 두 손가락을 벌리거나 모아 확대·축소합니다.
- 터치 기기는 자동 감지합니다. 터치 노트북 등에서는 메뉴 → 조작 방법·설정 → 터치 조작 사용으로 전환할 수 있습니다. PC의 WASD·마우스·Space·Z 조작은 유지합니다.
- 메뉴 열기, 터치 취소, 화면 회전, 포커스 이탈 시 누르고 있던 입력을 해제합니다. 화면에 돌아온 뒤 조이스틱을 다시 누르면 됩니다.
- 세로·가로 화면, 안전 영역 여백, 스크롤 가능한 메뉴를 지원합니다. 가로 화면에서는 학교를 더 넓게 볼 수 있습니다.
- 터치 모드에서는 픽셀 비율을 최대 1.25로 제한하고 실시간 그림자를 꺼 GPU 부담을 줄입니다. 교실 구조·가구·벽 충돌은 그대로 사용합니다. 실제 기기의 성능을 측정한 것은 아니며 오래된 휴대폰은 느릴 수 있습니다.

## 검사 범위

Chromium 모바일 에뮬레이션과 실제 브라우저 멀티터치 입력으로 세로 390×844, 가로 844×390의 이동·시점·점프 동시 입력, 정지, 인사, 취소, 메뉴 복귀, 화면 회전, 엘리베이터·층 선택 및 항공뷰 핀치를 검사했습니다. iPhone/Safari·Android 실물 기기 검증은 별도입니다. 모바일 입력은 기존 이동·점프 물리를 그대로 사용하며 공개 배포는 별도 요청 시 진행합니다.

포인터별 캡처·취소 처리는 [MDN Pointer events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events), 게임 표면의 브라우저 스크롤 방지는 [MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/touch-action)을 참고했습니다.
