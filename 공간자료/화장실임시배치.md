# 남녀 화장실 임시 배치

- 적용 범위: 1~4층 본관 화장실 두 곳과 별관 화장실 한 곳. 기존 12개 공간을 남녀 24개 공간으로 분리했습니다.
- 복도에서 화장실을 정면으로 바라볼 때 왼쪽은 여자, 오른쪽은 남자입니다. 본관은 지도상 서쪽/동쪽, 별관은 지도상 남쪽/북쪽입니다.
- 본관은 뒤쪽으로 1.2m, 별관은 운동장 방향으로 1.2m 확장했습니다. 인접 교실·계단, 복도 폭은 유지했습니다. 모델 단위 기준의 임시 치수이며 실측 치수가 아닙니다.
- 각각 독립된 출입구, 바닥·벽 타일, 세면대 2개, 거울, 칸막이 3칸과 변기를 넣었습니다. 본관·별관 모두 입구에서 안을 바라볼 때 세면대와 거울은 왼쪽입니다. 남자 화장실은 오른쪽에 소변기와 가림판을 배치했으며 소변기는 기존 2개에서 4개로 늘렸습니다.
- 출입구는 열려 있고 칸문은 접어 열린 상태로 표현했습니다. 벽·칸막이·기구는 통과할 수 없고 각 칸까지 이동할 수 있습니다.
- 실내 사진을 아직 받지 않아 기구 수·색상·배치는 임시입니다. 사진을 받으면 실제 특징으로 교체합니다. 거울은 경량 표면 표현이며 실시간 반사는 아닙니다.
- Blender 원본, 원본 구조 JSON, 촬영 폴더는 수정하지 않습니다. 웹에서만 배치 보정을 적용합니다.
